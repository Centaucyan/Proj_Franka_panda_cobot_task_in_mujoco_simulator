1. H/W 구성
  - 로봇1과 2는 Franka Emika Panda(model 폴더 내에 있음)
  - 로봇1과 2 모두 그리퍼 부분 가운데에 depth 카메라 하나씩 부착되어 있음
  - 버튼 스위치
    : On/Off, Start/Stop, 뒤로가기, Emergency-Stop

2. 역할
  - 로봇1
    : 부품 적재함에서 조립 과정의 부품 인식 및 불량품 검수
    : 조립 부품을 부품 대기 공간으로 pick and place
    : 부품 불량 시 불량품 적재함으로 pick and place
    : 부품 대기 공간에 아무 부품이 없다면 다음 부품을 부품 적재함으로부터 pick and place
    : 부품 적재함이 10%정도 남았을 경우 공정 시스템(외부 시스템)에 알림 

  - 작업자
    : 부품 대기 공간으로부터 부품을 작업 공간으로 가져온 후 조립
    : 완성품은 검수 공간으로 완성품 위치

  - 로봇2
    : 작업자 위치 확인
    : 검수 공간에서 완성품 인식 및 불량품 검수
    : 완성품이 정상이면 완성품 적재함으로 pick and place
    : 완성품이 불량이면 불량품 적재함으로 pick and place
    : 불량품 적재함 및 완성품 적재함이 90% 차지하면 공정 시스템(외부 시스템)에 알림
  
  - 버튼 스위치
    : On/Off 버튼 => 시스템 On/Off
    : Start/Stop 버튼 => 시스템 일시정지, 재시작
    : 뒤로가기 버튼 => 현재 공정의 전단계 작업 재실행
    : Emergency-Stop => 비상시 Off. 로봇 움직임 급멈춤.

2. 안전
  - 2d lidar를 이용해서 로봇 근처의 위험할 수 있는 공간에 움직임이 포착되면 로봇을 멈추게 한다.
    : 경고 구역과 위험 구역으로 나누어 경고 구역에서는 감속, 위험 구역에서는 Emergency-Stop.
  - 로봇팔의 depth 카메라를 이용해서 place할 공간에 움직임이 포착되면 로봇은 일시 정지. 

3. 정상 작동 시나리오
  - 작업자가 시스템 전원을 On
  - 시스템 점검 정상임을 확인(카메라, 라이다, 부품 적재함, 완성품 적재함, 불량품 적재함
  - 작업자가 Start 버튼을 누름
  - 로봇1이 부품 적재함에서 pick할 부품을 인식 후 불량품인지 점검
  - 부품이 불량이라면 불량품 적재함으로 pick and place
  - 부품이 정상이라면 부품 대기 공간으로 pick and place
  - 작업자는 로봇1이 놓은 부품을 작업 공간으로 가져와서 조립
  - 로봇1은 부품 대기 공간 빈 것을 인식 후 다음 부품 pick and place
  - 작업자는 완성품을 검수 공간으로 위치 시킴
  - 로봇2는 검수 공간의 완성품을 인식 후 불량품 검수
  - 완성품이 불량으로 인식되면 불량품 적재함에 pick and place
  - 완성품이 정상으로 인식되면 완성품 적재함에 pick and place
  - 휴식시간이나 근무시간 종료 시 작업자는 Stop 버튼을 누름

4. 예외 상황 시나리오
  - 상황1) 부품 대기 공간이나 검수 공간에 작업자 손이 있음
    : 대응 => 로봇 일시 정지
  - 상황2) 로봇방향으로 작업자 외 3자가 진입 시
    : 대응 => 경고 구역 내에 진입 시 로봇 감속, 위험 구역 내에 진입 시 즉시 멈춤
  - 상황3) 로봇1이 place 한 부품이 불량일 경우
    : 대응 => 작업자는 뒤로가기 버튼을 누름으로써 전 작업을 재실행하도록 함
  - 상황4) 작업자가 Start/Stop 버튼을 누르지 않고 자리를 비웠을 경우
    : 대응 => 로봇2의 depth 카메라가 인식 후 시스템 일시 정지. 일시 정지 시간 10분이 지나면 시스템 Off
  - 상황5) 부품 적재함에 부품이 10% 남음
    : 로봇1이 공정 시스템(외부 시스템)에 알림
  - 상황6) 불량품 적재함, 완성품 적재함 90% 채움
    : 로봇2가 공정 시스템(외부 시스템)에 알림
