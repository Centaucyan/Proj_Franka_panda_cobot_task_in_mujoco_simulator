1. H/W 구성
  - 로봇1과 2는 Franka Emika Panda(model 폴더 내에 있음)
  - depth 카메라 2ea
    : 로봇1과 2 모두 그리퍼 부분 가운데에 depth 카메라 하나씩 부착되어 있음
  - 버튼 스위치
    : On/Off, Start/Stop, Emergency-Stop
  - 2d-lidar 2ea
    : 물류 분류 작업대 작업자 이동하는 측면에 각각 설치

2. 역할
  - 로봇1(물류 A-Red, B-Blue, C-Green 분류), 로봇2(물류 A-Green, B-Red, C-Blue 분류)
    : 물류 분류 작업대에서 물류품 인식 후 적절한 적재함에 pick and place
    : 분류 불가 물류품은 분류 불가품 위치로 pick and place
    : 물류 적재함이 90% 이상 차지 시 공정 시스템(외부 시스템)에 알림

  - 작업자
    : 분류될 물품을 물류 분류 작업대에 펼쳐 놓음
    : 물류 적재함이 차면 이동 시킴
  
  - 버튼 스위치
    : On/Off 버튼 => 시스템 On/Off. Off시 현재 진행 중인 작업 마무리 및 로봇 초기 위치(부하 최저 위치)로 이동.
    : Start/Stop 버튼 => 시스템 일시정지, 재시작
    : Emergency-Stop => 비상시 Off. 로봇 움직임 급멈춤.

3. 안전
  - 2d lidar를 이용해서 로봇 근처의 위험할 수 있는 공간에 움직임이 포착되면 로봇을 멈추게 한다.
    : 경고 구역과 위험 구역으로 나누어 경고 구역에서는 감속, 위험 구역에서는 Emergency-Stop.
  - 작업자가 물류 분류 작업대로 다가오면 로봇은 감속

4. 작업 공간 조건
  - 분류 불가품은 컨베이어 벨트로 연결되어 불가품 실시간 이동

5. 정상 작동 시나리오
  - 작업자가 시스템 전원을 On
      - 시스템 점검 시작 후 작업자가 정상임을 확인(카메라, 라이다, 각각 물류 적재함 차지률 등)
  - 작업자가 Start 버튼을 누름
      - 로봇 1, 2는 각각 로봇과 가까운 아이템부터 인식 후 분류 적재함에 pick and place
          - 분류 적재함에 place 후 적재함 전체 스캔한 다음 적재함 자치율 계산
      - 물품이 분류 불가일 경우 분류 불가품 구역으로 pick and place
      - 로봇팔 초기 위치로 이동 후 다시 가까운 아이템부터 분류 작업 개시
      - Start 버튼 누른 이후 과정 반복
  - 작업자 시스템 전원 Off
      - 로봇이 현재 작업 중인 과정 마무리 후 초기 위치로 이동
      - 시스템 순차적으로 Off

6. 예외 상황 시나리오
  - 상황1) 물류 분류 작업대 근처에 작업자가 있을 경우
    : 대응 => 로봇 일시 정지
  - 상황2) 로봇 방향으로 이동체가 있을 경우
    : 대응 => 경고 구역 내에서는 로봇 작업 속도 감소. 위험 구역 내에서는 Emergency-Stop
  - 상황3) 로봇1과 2의 이동 경로가 겹치는 경우
    : 대응 => 두 로봇 중 먼저 작업을 시작한 로봇은 그대로 작업. 나머지 로봇은 경로 회피 후 일시 정지. 경로 상 충돌 위험 해지 시 작업 재시작
  - 상황4) 물류 분류 작업대에 분류 작업이 모두 끝났을 경우
    : 대응 => 시스템 일시 정지 후 공정 시스템(외부 시스템)에 알림. 10분 동안 물류 분류 작업대에 물품이 채워지지 않으면 시스템 Off
   - 상황5) 물류 적재함이 모두 찼을 경우
    : 대응 => 해당 물류 적재함이 모두 찼음을 공정 시스템(외부 시스템)에 알린 후 그 물류는 분류 작업에서 제외
